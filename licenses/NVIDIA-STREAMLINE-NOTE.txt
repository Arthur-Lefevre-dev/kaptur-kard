NVIDIA DLSS 5 Neural Rendering runtime (`nvngx_dlssnr.dll`, NGX feature 18) is
NOT redistributed in this repository.

To enable Mode C (`--features dlss`), place a legally obtained `nvngx_dlssnr.dll`
in %APPDATA%\CaptureView\dlss5-nr\ (or CAPTUREVIEW_DLSSNR_DIR). See docs/DLSS.md.

NVIDIA RTX SDKs license:
  https://github.com/NVIDIA/DLSS/blob/main/LICENSE.txt

The MIT-licensed D3D12 bridge under native/dlss5-nr/ is adapted from
ComfyUI-DLSS5-NR; it does not include NVIDIA proprietary binaries.
The NGX core `_nvngx.dll` is loaded from the installed NVIDIA driver.
